## はじめに読むもの

```
1. PROJECT.md          … プロジェクトの憲法。前提・制約・役割分担・匿名化ルール
2. docs/進捗.md        … 現在地と次にやること
3. docs/環境台帳.md    … 何ができて何ができないか【最重要資産】
4. docs/要件.md        … 何を作るか
```

そのうえで、自分の役割に応じて読む。

| 役割 | 読むもの |
|---|---|
| Web版 / ローカル Claude Code | `CLAUDE.md` |
| Codex（実装） | `AGENTS.md` |

**環境台帳を読まずに設計を語らないこと。**
「動くはず」と考えた機能が使えなかった例が何度もある。

**`docs/要件.md` §1.5 を読まずに実装を書き直さないこと。**
要件書に書かれていない挙動が、実装にだけ存在する。

## 開発フロー

```
Web版 Claude Code
  ↓ GitHub
ローカル Claude Code
  ↓ 実装指示
Codex
  ↓ 実装結果
ローカル Claude Code
  ↓ GitHub
Web版 Claude Code
```

**受け渡しは必ず GitHub を経由する。**
Web版がpushする際に作業ブランチが作られる場合があるため、
**特定のブランチへの直接pushを前提にせず、正しい最新の状態を確認してから作業する。**

実行環境側への受け渡しは、従来どおり ZIP で取得する。

詳細は `docs/AI運用.md`。
